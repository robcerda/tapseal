# Security

Report vulnerabilities privately through GitHub: **Security → Report a
vulnerability** on this repository. Please don't open public issues for them.

Useful reports name the format or flow involved (see docs/SPEC.md), the
adversary's position (host root, network, a malicious link, etc. per
docs/THREATS.md), and what they gain.

Out of scope, because the threat model accepts them: reading a secret while
it is live on the host, misuse by an agent you unlocked a secret for, and
attacks that require a compromised phone.
